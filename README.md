# Snav Website

Site do Snav Browser desenvolvido com React, TypeScript, CSS e Vite.

## Requisitos
- Node.js 20.19+ ou 22.12+
- npm

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

O build é gerado em `dist/`. O Vite usa caminhos relativos para suportar hospedagem na raiz de um domínio ou em subdiretórios, incluindo GitHub Pages.

## Tecnologias
- React — interface
- TypeScript — funcionalidades e tipagem
- CSS — identidade visual e responsividade
- Vite — desenvolvimento e compilação

Os arquivos de marca ficam em `public/favicon.png` e `public/icon.png`.
